# v0.6.1 — 插件图标改用作者头像

这一版只改图标，不动任何滚动逻辑。

## 改了什么

- `package.json` 的 `icon` 从 `./icon.svg`（蓝底闪电矢量图）改成 `./assets/avatar-180.jpg`（作者 GitHub 头像，180×180，8 KB）。
- DSH 插件管理页面（列表行、卡片、详情页）读取的就是这个字段，重启后即显示头像。
- `icon.svg` 仍随包发布，只是不再是默认图标。
- `files` 增加 `assets/avatar-180.jpg`；README 的「插件简介与图标」段落同步更新。

## 为什么

dshmarket 从 1.70 起优先渲染 catalog 里声明的 `icon`，没声明才回退作者头像（dsh-market#920）。
想统一成头像，两处都要改：catalog 条目去掉 `icon:`（awesome-dsh-plugin PR），包内 manifest 指向头像。

## 验证

`npm test` 全过（meta / regression / smoke），meta 输出 `icon=8066B`。
滚动逻辑与 0.6.0 完全一致，无行为变更。
