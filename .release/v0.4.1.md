# v0.4.1 — 展开后的行也会跟着重测

## 修了什么

- **展开思考过程 / 工具输出后滚动会跳**：行被标记后 `--sb-h` 的旧值会一直留着。现在带
  `data-expanded` / `data-open` / `data-chat-motion` / `hidden` 的元素一旦变化，插件只重新测量
  **它所在的那一行**，把新高度写回占位。行滚出视野再滚回来时，滚动条位置不再跳。
- **行内 sticky 不再被无谓跳过**：`content-visibility` 只在行离屏时生效，行在视口内没有
  containment，折叠头、代码块横幅照常吸顶。实测两种模式下截图与几何完全一致，因此 `sticky`
  这一条跳过规则被移除，含 sticky 子元素的行现在也会被优化。
- **属性变化不再扫描整个对话**：旧实现收到一次 `data-expanded` 变化会遍历页面里所有已标记行，
  展开一个大块时是 O(行数) 的扫描。现在只在 `target.closest("[data-scrollboost-row]")` 上处理。
- **轨迹表的每帧重建不再触发扫描**：`[data-trajectory-scroll]` 内的新增节点被忽略，切换标签页
  时不再为此排队一次文档扫描。

## 实测

- 600 行聊天复刻页：`rows 600 / marked 600 / skipped 0`，首帧可见标记 20ms，`scrollHeight`
  28470 → 28462（-8px，亚像素舍入），`--sb-h` 保留两位小数。
- sticky 行验证：`contain-intrinsic-size` 与真实高度一致时，`scrollTop`、行位置、吸顶位置、
  `scrollHeight` 与无插件时完全相同。
- `npm test`：meta / regression / smoke 全过；`npm run test:browser`：chat 600 行、drift 夹具、
  轨迹静态规则全部通过。
