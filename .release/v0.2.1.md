插件简介与图标：让 DSH 的插件列表里显示中文名与说明，而不是裸包名。

## 变更
- 新增 `locale/en.json` 与 `locale/zh.json` 字典：插件列表显示 **滚动加速**（英文 `Scroll Boost`）与一段中文简介。
- 新增 `icon.svg`（873 B，蓝底 + 白色滚动行 + 橙黄闪电）。
- `package.json` 增加 `icon` 字段与 `./locale/*.json` 导出，`files` 收录 `locale`、`icon.svg`。
- 新增 `test/meta.cjs`：校验字典字段、中英文差异、图标路径/类型/大小（≤256 KiB）、`files` 与 `exports` 覆盖。

## 安装
```powershell
dsh plugin --profile desktop add "github:TWFU-wcy/dsh-scroll-boost"
```
安装后完全重启 DSH。

## 说明
简介的读取规则来自 DSH 自身：先解析 `<包>/locale/en.json`，再枚举同目录所有 `*.json` 作为语言字典；
图标取 `package.json` 的 `icon`（包内相对路径）。
